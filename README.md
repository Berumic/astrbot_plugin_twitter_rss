# astrbot_plugin_twitter_rss (v1.4.0)

基于 [AstrBot](https://docs.astrbot.app/) 的 **Twitter / X 多源 RSS 智能订阅、分群独立标签过滤与《今日要闻》日报渲染插件**。

## 核心特性

1. **多源自动回退抓取（免 API Key）**
   - 内置 `FxTwitter RSS`、`FixupX RSS`、`FxTwitter JSON API`、多节点 `RSSHub` 与 `Nitter` 自动回退机制，彻底解决单一公共 RSSHub 404 问题。
2. **按群聊独立订阅与标签过滤（`group_subscriptions`）**
   - 每个群聊拥有独立的订阅账号列表（`twitter_accounts`）与独立的标签过滤规则：
     - **必须包含标签（`must_include_image_tags`）**：画面必须全部命中才通过。
     - **其他任意标签（`any_include_image_tags`）**：只需命中其中任意一条即通过。
     - **禁止包含标签（`exclude_image_tags`）**：命中任意一条即拦截。
3. **无黑边推文卡片渲染 + 原图单独发送**
   - 仅保留干净的推文主体卡片，自动通过 `Pillow` 裁切视口多余像素，彻底消除黑边。
   - 推文下方自动附上中文**正文直译**与推特蓝（`#1d9bf0`）**标签翻译**；若原推文无正文，则自动省略正文翻译、仅保留蓝色标签。
   - 推送时先发送渲染好的推文卡片，再单独发送高清原图。
4. **马卡龙色系《今日要闻》24 小时精选长图**
   - 定时（或手动 `/tw digest`）汇总各群过去 24 小时推文，采用精炼新闻快讯口吻提炼要闻。
   - 随机搭配 8 套马卡龙色系（樱花奶霜、薄荷海盐、杏桃奶油、香芋薰衣草、苏打冰蓝、柠檬奶酪、抹茶开心果、树莓珊瑚），含图推文自动将插画融入卡片右侧背景并向左侧马卡龙底色平滑渐变过渡。

## 群聊管理指令

在需要管理的群聊中直接发送以下指令（所有操作仅针对当前群聊独立生效）：

| 指令 | 说明 |
| :--- | :--- |
| `/tw sub [群备注名]` | 绑定并启用当前群聊的独立订阅配置 |
| `/tw unsub` | 移除当前群聊的独立订阅配置 |
| `/tw add <推特账号>` | 为当前群聊添加订阅账号（无需带 `@`） |
| `/tw del <推特账号>` | 从当前群聊移除订阅账号 |
| `/tw list` | 查看当前群聊的订阅账号与三类标签规则 |
| `/tw tag_must_add <标签>` / `/tw tag_must_del <标签>` | 添加 / 删除当前群聊【必须包含】的图片标签 |
| `/tw tag_any_add <标签>` / `/tw tag_any_del <标签>` | 添加 / 删除当前群聊【其他任意】的图片标签（命中其一即可） |
| `/tw tag_exc_add <标签>` / `/tw tag_exc_del <标签>` | 添加 / 删除当前群聊【禁止包含】的排除图片标签 |
| `/tw test [账号或数量] [数量]` | 按当前群聊规则测试抓取并筛选推送（默认每号 3 条，可在面板配置） |
| `/tw check` | 立即对所有已启用群聊执行一次增量轮询检查 |
| `/tw digest` | 立即生成并推送当前群聊过去 24 小时的《今日要闻》长图 |
| `/tw status` | 查看插件全局运行状态与各群配置概览 |

## 安装方式

- **方式一（GitHub 仓库安装）**：在 AstrBot 管理面板「插件市场 -> 安装插件」中输入本仓库 GitHub 地址直接安装。
- **方式二（本地解压安装）**：将本项目解压至 `AstrBot/data/plugins/astrbot_plugin_twitter_rss` 目录下，在 WebUI 插件管理中点击重载即可。
