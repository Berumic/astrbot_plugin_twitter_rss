# astrbot_plugin_twitter_rss

AstrBot 的 Twitter / X 订阅插件：按群订阅账号与话题标签，通过 AI 筛选、翻译后推送卡片，并生成《今日要闻》日报。无需 X 官方 API Key。

## 功能

- **分群订阅**：各群独立配置账号、话题标签、推送类型及 AI 筛选规则。
- **多源抓取**：RSS / JSON 自动回退，同一订阅每轮只抓取一次，再按各群规则分别处理。
- **推文卡片**：正文与标签翻译、转推与引用转推识别、高清原图、站外链接，支持合并转发。
- **AI 筛选**：文本价值判断、图片标签匹配；匹配标签和拦截原因仅记录在后台日志。
- **每日简报**：从本群订阅的缓存推文中精选要闻，生成长图、归档，并支持当日失败补发。

## 安装与开始使用

1. 在 AstrBot 插件管理中通过仓库地址安装：<https://github.com/Berumic/astrbot_plugin_twitter_rss>。
2. 在插件配置中选择文本模型 `text_provider_id` 和视觉模型 `vision_provider_id`，按需填写代理。
3. 在目标群发送 `/tw sub 群备注名`，再用 `/tw add 账号` 或 `/tw tag_add 标签` 添加订阅。
4. 使用 `/tw list` 查看配置，使用 `/tw test 2` 测试本群随机两个订阅。

也可将插件解压到 AstrBot 的 `data/plugins/astrbot_plugin_twitter_rss` 目录。插件根目录须包含 `metadata.yaml`、`main.py`、`furigana.py`、`_conf_schema.json`、`requirements.txt` 、`fonts/` 字体目录及模板文件；`tests/` 无需打包。配置保存后重载插件生效。

## 配置

| 配置分组 | 内容 |
| --- | --- |
| 分群订阅 | 本群账号、话题标签、独立推送开关、AI 筛选规则及日报开关 |
| 全局推送配置 | 图片、纯文字、回复、转推、引用转推的默认策略 |
| 推送样式与链接 | 卡片与原图发送方式、合并转发、站外链接（默认附带，可关闭） |
| AI 模型与筛选 | 文本与视觉模型、翻译和筛选选项 |
| 抓取与并发配置 | 轮询间隔、抓取与处理并发、默认测试数量 |
| 订阅源与网络配置 | 账号订阅源、标签搜索源、回退源和代理 |
| 每日简报配置 | 日报总开关、发送时间、精选条数与提示词 |

**独立推送开关**：选择账号或 `#标签`，分别设置转推（RT）、引用转推、回复、纯文字、图片五项策略。每项提供「默认 / 推送 / 直接推送 / 不推送」；「推送」继续经过 AI 筛选，「直接推送」跳过 AI 内容审核。切换账号会保留选择，保存并重载后显示修改标记。

**图片筛选**：必须包含标签须全部命中；任意包含标签须至少命中一项；排除标签命中任意一项即拦截。话题标签订阅与这些视觉标签是两种不同功能。

**日语汉字注音**：在「推送样式与链接」中开关，默认开启；「日语原文注音样式」可选择「平假名」（默认）或「罗马音」（赫本式）。在日语原文与引用推文的汉字上方显示小号注音，正文和话题标签均支持；中文译文保持不变。本地词典生成，不额外调用 AI；人名、多音字等读音可能有误。纯汉字且无假名的内容不自动注音，避免将中文按日语标注。

**代理**：可填写 `127.0.0.1:7890` 或完整的 `http://127.0.0.1:7890`；支持 HTTPS、SOCKS5（需安装 `socksio`）。留空不指定代理。

## 群聊指令

订阅操作均针对当前群；缓存清理作用于整个插件。管理员指群管理员、群主或机器人管理员，实际权限还受 AstrBot 配置影响。

### 普通成员

| 指令 | 功能 |
| --- | --- |
| `/tw sub [备注名]` | 绑定本群订阅配置 |
| `/tw add <账号>` | 添加本群账号订阅 |
| `/tw list` | 查看本群订阅与筛选规则 |
| `/tw news [日期]` | 查看日报归档列表或发送指定日期的日报；别名 `/tw history` |

日期支持 `2026-10-20`、`10-20`、`20261020`、`今天`、`昨天`、`前天`。

### 管理员

| 指令 | 功能 |
| --- | --- |
| `/tw unsub` | 删除本群整套订阅配置 |
| `/tw del <账号>` | 移除本群账号订阅 |
| `/tw tag_add <标签>` / `/tw tag_del <标签>` | 添加 / 移除话题标签订阅 |
| `/tw must_add <标签>` / `/tw must_del <标签>` | 修改必须包含的图片标签 |
| `/tw any_add <标签>` / `/tw any_del <标签>` | 修改任意包含的图片标签 |
| `/tw exc_add <标签>` / `/tw exc_del <标签>` | 修改排除图片标签 |
| `/tw set <账号> [类型] [策略]` | 查看或修改独立推送策略；类型为转推、回复、纯文字、图片或全部，策略为默认、推送、直接推送或不推送 |
| `/tw test [数量]` | 随机选择本群 N 个订阅，各抽取一条推文，默认三个订阅 |
| `/tw test <账号> [条数]` | 仅从指定账号随机抽取 N 条推文，如 `/tw test nipeira 2` |
| `/tw check` | 检查本群全部账号与标签订阅的新推文 |
| `/tw digest` | 生成本群当前最近 24 小时的日报并归档 |
| `/tw clear [cache\|archive\|all]` | 清理推文与图片缓存 / 日报归档 / 全部缓存及已读记录 |

`test` 不会因失败或候选不足而追加其他订阅；类型开关与 AI 筛选仍生效，实际推送数可能少于指定数量。可测试已读推文。纯数字账号用 `/tw test @12345` 或 `/tw test 12345 2` 指定。

`test`、`check` 若遇到后台任务运行会排队等待；后台扫描仍独立执行。日志区分「随机测试 群[…]」「手动检查 群[…]」和「后台扫描 全部群聊」。

## 标签搜索源

在本群标签列表中每行填写一个话题标签，可省略 `#`，支持中日文、字母、数字和下划线；不支持空格、任意搜索表达式或分页。

`hashtag_search_url` 使用带 `{query}` 占位符的 RSS 搜索地址，插件会将其替换为编码后的 `#标签`。内置 Nitter 主源与回退候选，可在 `hashtag_search_fallback_urls` 中调整；公共实例可能限流、停用或延迟更新，可参考 [Nitter 实例状态](https://status.d420.de/)。

也可使用自建 RSSHub 的 `/twitter/keyword/{query}` 路由，实例需自行配置搜索认证。普通 FxTwitter 账号时间线接口不支持标签搜索。搜索源须返回 RSS 2.0，条目链接须包含 `/作者/status/推文ID`。

标签结果沿用本群推送策略、AI 筛选和已读规则，也会纳入本群日报。

## 日报与补发

- **统计范围**：定时日报使用设定推送时刻之前 24 小时的缓存推文。例如 20 日 08:30 的日报，统计 19 日 08:30 至 20 日 08:30。
- **内容精选**：按本群账号与标签选取素材，再由 AI 精选、撰写摘要。素材不局限于已成功推送的推文。
- **当日补发**：各群独立记录送达状态，失败每五分钟重试，成功后停止；重启后保留进度。补发沿用同一期已保存的条目，过本地午夜后不再补发前一天日报。
- **图片与归档**：渲染结果校验失败会重试一次，无效内容不会上传。长图与条目元数据保存在 `digest_archive/`，图片损坏或缺失时可按元数据重建。
- **手动生成**：`/tw digest` 使用执行时最近 24 小时；`/tw news <日期>` 调取已归档内容。

## 抓取与重试说明

每轮抓取结果共享，各群独立筛选、推送和记录已读。同群账号与标签命中同一推文时去重；筛选未通过也记为已读。正常重启保留已读记录，后续轮询仍会请求源站发现更新。

首次定时抓取默认仅标记历史已读，首次手动检查最多处理两条。确认账号不存在后会自动移除订阅。

普通推文整条发送失败时不标记成功，下轮仍抓到该条就重试；卡片成功但部分原图失败时，目前不会自动补发缺失原图。平台实际送达却返回错误时，重试可能产生重复消息。

抓取并发默认 4，处理并发默认 3。同源请求串行并限制间隔，不同站点可并行；FxTwitter、FixupX 与 FxTwitter API 共用源站限速。源站限流或异常时冷却并回退；本地 `PoolTimeout` 会重建连接池并重试，不视为源站封禁。
