# astrbot_plugin_twitter_rss (v1.4.0)

基于 [AstrBot](https://docs.astrbot.app/) 的 **Twitter / X 多源 RSS 智能订阅、分群独立标签过滤与马卡龙《今日要闻》日报渲染插件**。

## ✨ 核心特性

1. **多源自动回退抓取 & 无效 ID 自动清理（免 API Key）**
   - 内置 `FxTwitter RSS`、`FixupX RSS`、`FxTwitter JSON API`、多节点 `RSSHub` 与 `Nitter` 自动回退机制，彻底解决单一公共 RSSHub 404 问题。
   - **不存在 ID 自动移除**：添加订阅、测试推送或定时轮询时，自动通过权威接口核验账号状态；若确认该推特 ID 不存在或已注销（404），自动从群聊订阅列表中移除并保存配置。

2. **按群聊独立订阅与三类视觉标签过滤（`group_subscriptions`）**
   - 每个群聊拥有独立的订阅账号列表（`twitter_accounts`）、独立的文本筛选提示词与独立的视觉标签过滤规则：
     - **必须包含标签（`must_include_image_tags`）**：画面必须**全部命中**才通过。
     - **其他任意标签（`any_include_image_tags`）**：只需**命中其中任意一条**即通过。
     - **禁止包含标签（`exclude_image_tags`）**：命中任意一条即直接拦截。

3. **无黑边推文卡片渲染 + 转推/引用识别 + 多图合并转发**
   - **无黑边纯净卡片**：仅保留推文主体，渲染后通过 `Pillow` 自动裁切视口多余像素，彻底消除黑边。
   - **正文与蓝色标签翻译**：推文下方自动附上中文正文直译与推特蓝（`#1d9bf0`）标签翻译；若原推文无正文，则自动省略正文翻译、仅保留蓝色标签。
   - **精准转推跳过与引用卡片渲染**：自动识别纯转推（含仅带原推链接的无配文转推）并按配置默认跳过；带配文的引用转发（Quote Tweet）自动剥离正文裸链接，渲染为仿原生 X 的圆角嵌套引用框（`.quote-card`）；通过画师主页接口独立获取本人真实头像，绝不与被转发对象头像混淆。
   - **原图单独发送 & 超 3 图合并转发**：默认先发送渲染好的推文卡片，再单独发送高清原图；当总图片数超过阈值（默认 > 3 张）时，自动切换为 QQ 群合并转发（`Comp.Nodes`，QQ 官方接口自动回退为单条多图消息链发送）。

4. **自适应马卡龙《今日要闻》24 小时精选长图 & 本地历史归档**
   - **上限控制 + AI 自主精选**：设定每日精选条数上限（`daily_digest_max_items`），由 AI 在上限内自主判断并筛选真正具备资讯/作品发布价值的要闻条目（宁缺毋滥，不凑水帖），采用干练新闻简讯口吻撰写并自动过滤“无法判断/未进一步说明”等废话。
   - **插画主色相提取 + Alpha 透明度无缝渐变**：含图要闻自动将插画作为卡片右侧背景，通过 `CSS mask-image` 控制图片自身 Alpha 通道从右向左平滑透明过渡；同时提取插画主导色相生成对应的马卡龙卡片底色，无图卡片随机搭配内置 8 套马卡龙色卡，顶部「今日要闻」标题 UI 通过全词条色相环聚类与圆周向量合成动态匹配整期色调。
   - **本地持久化归档与按日期调取**：每日生成的《今日要闻》长图与元数据自动归档保存在本地 `digest_archive/` 目录，随时可通过指令按日期调取往期要闻。

## 💬 群聊管理指令

在需要管理的群聊中直接发送以下指令（除全局检查与缓存清理外，所有订阅与标签操作均**仅针对当前群聊独立生效**）：

### 订阅与标签管理
| 指令格式 | 功能说明 |
| :--- | :--- |
| `/tw sub [群备注名]` | 绑定并启用当前群聊的独立订阅配置 |
| `/tw unsub` | 移除当前群聊的独立订阅配置 |
| `/tw add <推特账号>` | 为当前群聊添加订阅账号（无需带 `@`，若 ID 不存在会自动检测并移除） |
| `/tw del <推特账号>` | 从当前群聊移除订阅账号 |
| `/tw list` | 查看当前群聊的订阅账号、三类标签规则与配置状态 |
| `/tw must_add <标签>` / `/tw must_del <标签>` | 添加 / 删除当前群聊【必须包含】的图片标签（全部命中才通过） |
| `/tw any_add <标签>` / `/tw any_del <标签>` | 添加 / 删除当前群聊【其他任意】的图片标签（命中任意 1 条即通过） |
| `/tw exc_add <标签>` / `/tw exc_del <标签>` | 添加 / 删除当前群聊【禁止包含】的排除图片标签 |

### 推送测试、今日要闻与历史归档调取
| 指令格式 | 功能说明 |
| :--- | :--- |
| `/tw test [账号]` | 按当前群聊规则获取每个账号过去 $N$ 条非转推推文（默认 3 条，可在面板配置）进行筛选推送 |
| `/tw check` | 立即手动检查当前群聊所有订阅账号的新推文并推送 |
| `/tw digest` | 立即汇总本群过去 24 小时推文，生成《今日要闻》长图推送并归档至本地 |
| `/tw news`（或 `/tw history`） | 查看本群本地已归档保存的所有历史《今日要闻》日期列表 |
| `/tw news <日期>`（或 `/tw history <日期>`、`/tw digest <日期>`） | 调取本群指定日期的《今日要闻》长图（支持 `2026-10-14`、`10-14`、`20261014`、`今天`、`昨天`、`前天`） |

### 本地缓存清理
| 指令格式 | 功能说明 |
| :--- | :--- |
| `/tw clear` | 清理本地推文缓存（`history_tweets.json`）、图片与头像缓存（`img_cache/`）及内存缓存，保留历史日报归档与已读记录 |
| `/tw clear archive` | 仅清理本地保存的历史《今日要闻》归档长图与记录（`digest_archive/`） |
| `/tw clear all` | 彻底清空全部本地缓存（含推文缓存、图片缓存、历史日报归档与已读状态 `seen_ids`） |

## 📦 安装与配置方式

1. **GitHub 仓库安装**：在 AstrBot 管理面板「插件市场 -> 安装插件」中输入本仓库 GitHub 地址直接安装。
2. **本地解压安装**：将压缩包解压至 `AstrBot/data/plugins/astrbot_plugin_twitter_rss` 目录下，在 AstrBot WebUI「插件管理」中点击重载插件即可。
3. **WebUI 面板配置**：
   - 在插件配置中选择用于文本判断/翻译的 `text_provider_id` 与用于图片标签识别的 `vision_provider_id`（支持在群内直接用 `/tw` 指令管理各群订阅，也可在面板的 `group_subscriptions` 卡片列表中可视化编辑各群规则）。
   - 若处于国内网络环境，可在 `http_proxy` 中填入本地代理地址（如 `http://127.0.0.1:7890`）。
