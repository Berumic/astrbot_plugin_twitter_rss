# astrbot_plugin_twitter_rss (v1.4.0)

基于 [AstrBot](https://docs.astrbot.app/) 的 **Twitter / X 多源 RSS 智能订阅、分群独立标签过滤与马卡龙《今日要闻》日报渲染插件**。

## ✨ 核心特性

1. **多源自动回退抓取 & 无效 ID 自动清理（免 API Key）**
   - 内置 `FxTwitter RSS`、`FixupX RSS`、`FxTwitter JSON API`、多节点 `RSSHub` 与 `Nitter` 自动回退机制，彻底解决单一公共 RSSHub 404 问题。
   - **不存在 ID 自动移除**：添加订阅、测试推送或定时轮询时，自动通过权威接口核验账号状态；若确认该推特 ID 不存在或已注销（404），自动从群聊订阅列表中移除并保存配置。

2. **按群聊独立订阅与三类视觉标签过滤（`group_subscriptions`）**
   - 每个群聊拥有并列的订阅账号列表（`twitter_accounts`）和订阅标签列表（`twitter_hashtags`）、独立的文本筛选提示词与独立的视觉标签过滤规则：
     - **必须包含标签（`must_include_image_tags`）**：画面必须**全部命中**才通过。
     - **其他任意标签（`any_include_image_tags`）**：只需**命中其中任意一条**即通过。
     - **禁止包含标签（`exclude_image_tags`）**：命中任意一条即直接拦截。

3. **无黑边推文卡片渲染 + 转推/引用识别 + 多图合并转发**
   - **无黑边纯净卡片**：仅保留推文主体，渲染后通过 `Pillow` 自动裁切视口多余像素，彻底消除黑边。
   - **正文与蓝色标签翻译**：推文下方自动附上中文正文直译与推特蓝（`#1d9bf0`）标签翻译；若原推文无正文，则自动省略正文翻译、仅保留蓝色标签。
   - **精准转推跳过与引用卡片渲染**：自动识别纯转推（含仅带原推链接的无配文转推）并按配置默认跳过；带配文的引用转发（Quote Tweet）自动剥离正文裸链接，渲染为仿原生 X 的圆角嵌套引用框（`.quote-card`）；通过画师主页接口独立获取本人真实头像，绝不与被转发对象头像混淆。
   - **原图单独发送 & 超 3 图合并转发**：默认先发送渲染好的推文卡片，再单独发送高清原图；当总图片数超过阈值（默认 > 3 张）时，自动切换为 QQ 群合并转发（`Comp.Nodes`，QQ 官方接口自动回退为单条多图消息链发送）。

4. **自适应马卡龙《今日要闻》24 小时精选长图 & 本地历史归档**
   - **上限控制 + AI 自主精选**：设定每日精选条数上限（`daily_digest_max_items`），由 AI 在上限内自主判断并筛选真正具备资讯/作品发布价值的要闻条目（宁缺毋滥，不凑水帖），采用干练新闻简讯口吻撰写并自动过滤“无法判断/未进一步说明”等废话。
   - **插画主色相提取 + Alpha 透明度无缝渐变**：含图要闻自动将插画作为卡片右侧背景，通过 `CSS mask-image` 控制图片自身 Alpha 通道从右向左平滑透明过渡；同时提取插画主导色相生成对应的马卡龙卡片底色，无图卡片随机搭配内置 8 套马卡龙色卡，顶部「今日要闻」标题 UI 通过全词条色相环聚类与圆周向量合成动态匹配整期色调。
   - **本地持久化归档与按日期调取**：每日生成的《今日要闻》长图与元数据自动归档保存在本地 `digest_archive/` 目录，随时可通过指令按日期调取往期要闻。

## 💬 群聊管理指令

在需要管理的群聊中直接发送以下指令（除全局检查与缓存清理外，所有订阅与标签操作均**仅针对当前群聊独立生效**）：

### 1. 普通群成员可用指令（订阅与查看）
| 指令格式 | 默认权限 | 功能说明 |
| :--- | :---: | :--- |
| `/tw sub [群备注名]` | 群成员 | 绑定并启用当前群聊的独立订阅配置 |
| `/tw add <推特账号>` | 群成员 | 为当前群聊添加订阅账号（无需带 `@`，若 ID 不存在会自动检测并移除） |
| `/tw list` | 群成员 | 查看当前群聊的订阅账号、三类标签规则与配置状态 |
| `/tw news`（或 `/tw history`） | 群成员 | 查看本群本地已归档保存的所有历史《今日要闻》日期列表 |
| `/tw news <日期>`（或 `/tw history <日期>`） | 群成员 | 调取本群指定日期的《今日要闻》长图（支持 `2026-10-14`、`10-14`、`20261014`、`今天`、`昨天`、`前天`） |

### 2. 仅限管理员指令（删除、修改过滤规则、测试触发与清理缓存）
> 以下涉及删除配置、修改过滤规则、耗费模型额度及清空本地缓存的指令，默认均已添加 `@filter.permission_type(filter.PermissionType.ADMIN)` 及群管理员权限校验，**仅限群聊管理员/群主或机器人管理员**使用：

| 指令格式 | 默认权限 | 功能说明 |
| :--- | :---: | :--- |
| `/tw unsub` | 🔒 管理员 | 移除当前群聊的整套独立订阅配置 |
| `/tw del <推特账号>` | 🔒 管理员 | 从当前群聊移除已订阅的推特账号 |
| `/tw must_add <标签>` / `/tw must_del <标签>` | 🔒 管理员 | 添加 / 删除当前群聊【必须包含】的图片标签（全部命中才通过） |
| `/tw any_add <标签>` / `/tw any_del <标签>` | 🔒 管理员 | 添加 / 删除当前群聊【其他任意】的图片标签（命中任意 1 条即通过） |
| `/tw exc_add <标签>` / `/tw exc_del <标签>` | 🔒 管理员 | 添加 / 删除当前群聊【禁止包含】的排除图片标签 |
| `/tw set <账号> [转贴\|回复\|纯文字\|图片\|全部] [开启\|关闭\|默认]` | 🔒 管理员 | 为单个订阅账号独立设置四类推文是否推送（未配置项自动跟随全局默认；不带后两个参数可查看该账号当前策略） |
| `/tw tag_add <标签>` / `/tw tag_del <标签>` | 🔒 管理员 | 添加 / 移除当前群聊的推特话题标签订阅（如 `原神`、`#ブルアカ`） |
| `/tw test [账号]` | 🔒 管理员 | 按当前群聊规则获取每个账号过去 $N$ 条非转推推文进行筛选推送 |
| `/tw check` | 🔒 管理员 | 立即手动检查当前群聊所有订阅账号的新推文并推送 |
| `/tw digest` | 🔒 管理员 | 立即汇总本群过去 24 小时推文，生成《今日要闻》长图推送并归档至本地 |
| `/tw clear [cache\|archive\|all]` | 🔒 管理员 | 清理本地缓存（默认清理推文与图片缓存；`archive` 清理日报归档；`all` 清空全部本地缓存与已读记录） |

## 📦 安装与配置方式

1. **GitHub 仓库安装**：在 AstrBot 管理面板「插件市场 -> 安装插件」中输入本仓库 GitHub 地址直接安装。
2. **本地解压安装**：将压缩包解压至 `AstrBot/data/plugins/astrbot_plugin_twitter_rss` 目录下，在 AstrBot WebUI「插件管理」中点击重载插件即可。
3. **WebUI 面板配置**：
   - 在插件配置中选择用于文本判断/翻译的 `text_provider_id` 与用于图片标签识别的 `vision_provider_id`（支持在群内直接用 `/tw` 指令管理各群订阅，也可在面板的 `group_subscriptions` 卡片列表中可视化编辑各群规则）。
   - 若处于国内网络环境，可在 `http_proxy` 中填入本地代理地址（如 `http://127.0.0.1:7890`）。
   - 「单账号独立推送开关」选择账号后显示该账号的转贴 (RT)、回复、纯文字、图片四个下拉框，均提供「默认 / 推送 / 直接推送 / 不推送」。切换账号会保留前一个账号的选择；点击插件配置的保存按钮后写入配置，重新加载后账号选项显示「已修改」及具体策略。全部恢复「默认」会清除该账号的修改标记，旧版账号设置会自动迁移。

## 标签搜索订阅

群聊配置中「本群订阅的推特标签列表」与账号列表并列。每项填写一个话题标签（可省略 `#`），支持中日文、英文字母、数字和下划线，不接受空格或任意搜索表达式。此功能搜索不限作者的推文，与图片 AI 标签筛选不同。

「单账号独立推送开关」的「账号」下拉框也包含本群订阅标签，以 `#标签` 显示。标签可独立设置转贴、回复、纯文字、图片四项策略，均支持「默认 / 推送 / 直接推送 / 不推送」；切换选项保留各自设置，保存并重载后显示「已修改」标记。标签搜索结果按该标签的策略处理，「默认」跟随本群默认设置，与同名账号分别保存。

`hashtag_search_url` 默认使用 `https://nitter.kareem.one/search/rss?f=tweets&q={query}`，无需自行填写 Twitter 账号或 API 密钥，留空也使用这个默认源。插件将 `{query}` 替换为 URL 编码后的 `#标签`。2026-10-15 经当前机器代理实测，`#原神`、`#ブルアカ`、`#GenshinImpact` 分别返回并成功解析 15、17、18 条结果，包括真实作者和图片。候选来自 [Nitter 实例状态列表](https://status.d420.de/)，上述数量仅代表测试时结果，公共实例仍可能限流、停用或延迟更新。

`hashtag_search_fallback_urls` 提供按顺序尝试的回退预选：`nitter.meowing.monster`、`nitter.pp.ua`、`nitter.netbub.com`，均使用 `/search/rss?f=tweets&q={query}`。主源发生 HTTP 错误、超时、返回 HTML、无效 RSS 或空结果时，自动继续尝试下一源；获得非空有效 RSS 后停止。可在面板增删、调整顺序，清空列表可关闭回退。2026-10-15 当前出口实测，`meowing.monster` 曾返回 15 条有效搜索结果，随后复测触发 429 限流；`pp.ua` 和 `netbub.com` 返回 403，仅作为备用候选，不保证当前可用。

也可将主源或回退项改为自建 RSSHub，例如 `https://rss.example.com/twitter/keyword/{query}`；RSSHub 实例需自行配置 Twitter 搜索所需的 `TWITTER_AUTH_TOKEN` 或第三方接口，具体依版本而定。普通 FxTwitter 账号时间线不提供这个搜索接口。没有标签订阅时不会请求默认搜索站点。

搜索源须返回 RSS 2.0，每条结果的链接需包含 `/作者/status/推文ID`。支持 Nitter 和 X/Twitter 链接，解析后统一为标准 X 链接，插件据此识别真实作者、配图和推文 ID。标签结果沿用本群的类型开关、图片/文本 AI 筛选及首次历史已读设置，同一群内账号和多个标签命中的相同推文只处理一次，不同群独立处理。标签搜索素材也纳入本群日报范围。

可在面板填写标签，或发送 `/tw tag_add 原神`；使用 `/tw list` 查看账号和标签订阅，使用 `/tw check` 同时检查两种订阅。定时抓取首次命中默认只标记历史已读；首次手动检查最多处理两条。保存并重载插件后生效。暂不支持 X 官方 JSON 搜索 API、Atom 搜索源或搜索分页，单次结果数量取决于搜索源。
